# JJGo 글과 문구 작성 하네스

이 문서는 `app/`의 모든 공개 문구에 적용한다. Notes 본문뿐 아니라 홈, 소개, 컨설팅, 작품 설명, 버튼, 이미지 대체 텍스트, SEO 설명과 영어 문구까지 포함한다. 목표는 AI가 썼는지 판별하는 것이 아니라, 독자가 읽을 이유가 있는 정확한 문장을 남기는 것이다.

## 기준 자료

- **말투 기준:** 사용자가 글 형식의 기준으로 지정한 `app/notes/eternal-sunshine-content.ts`의 한국어 본문. 영화의 한 장면에서 시작해 기술을 떠올리고, 식당·비밀번호 같은 일상적인 예로 질문을 밀고 간다. 짧고 긴 문장이 섞여 있고, 마지막도 교훈을 선언하지 않는다. 이 글의 모든 문장이 사용자가 직접 쓴 원문인지는 별도로 확인되지 않았다.
- **사실 기준:** 해당 페이지의 기존 데이터, 사용자가 제공한 경험·기록, 확인 가능한 공개 자료. 문장의 말투가 자연스러워도 근거 없는 이력·성과·의견은 쓰지 않는다.
- `sample: true`인 Notes는 말투 기준 자료로 삼지 않는다. 공개 글처럼 소개하거나 샘플 표시를 제거하지 않는다.
- 사용자가 직접 쓴 원문을 받으면 이 절의 말투 기준을 그 원문으로 갱신한다. 원문의 고유한 버릇을 참고하되 문장을 복제하지 않는다.

## 공통 작업 순서

1. **말할 사실 한 줄:** 이 문구가 전달할 사실이나 독자가 할 행동을 먼저 적는다. 근거가 없는 주장은 삭제하거나 확인이 필요하다고 남긴다.
2. **대상 독자와 자리:** 홈의 짧은 소개, 작품의 실제 상태, 컨설팅의 제공 범위, 블로그의 개인적 관찰은 서로 다른 일을 한다. 같은 수사 문장을 모든 페이지에 돌려 쓰지 않는다.
3. **초안:** 추상어를 실제 대상·행동으로 바꾼다. `혁신`, `여정`, `미래`, `가능성`, `하나의 흐름`, `신뢰할 수 있는` 같은 말은 그 문장 안에서 무엇을 뜻하는지 설명할 수 있을 때만 쓴다. 기술 용어는 실제 기능이나 범위를 가리킬 때 유지한다.
4. **편집:** 같은 뜻을 반복하는 문장, 세 항목씩 균등하게 나열한 문단, 앞부분을 되풀이하는 결론, 관찰 없이 덧붙인 교훈을 지운다. 문장 길이와 리듬은 내용에 따라 바꾼다. 억지 농담이나 감탄사를 추가하지 않는다.
5. **사실과 상태 확인:** `만들었다`, `운영한다`, `검증했다`, `출시했다`는 각각 증거가 다르다. 계획·시제품·샘플을 완료된 실적으로 바꾸어 쓰지 않는다. 날짜, 수치, 외부 링크, 제품 상태를 확인한다.
6. **양언어 확인:** 한국어를 영어로 직역하거나 영어의 마케팅 관용구를 한국어로 옮기지 않는다. 두 언어에서 같은 사실과 상태를 말하되, 각각 자연스러운 문장으로 쓴다.
7. **화면 확인:** 빌드와 테스트를 실행하고 실제 렌더링에서 제목, 줄바꿈, 링크, 이미지, 메타 설명을 확인한다. 자동 검사는 말투를 판정하지 않는다.

## Notes 글의 추가 관문

본문을 쓰기 전에 아래 항목을 메모한다. 답이 없는 항목은 억지로 채우지 말고, 글의 범위를 줄이거나 샘플/초안으로 유지한다.

```text
주제와 독자:
내가 실제로 본 장면·한 일·막힌 지점:
독자가 따라갈 수 있는 구체적 사례:
이 글에서만 나오는 질문 또는 관찰:
확인한 사실과 출처:
확인하지 못한 부분:
글 끝에 남길 장면 또는 질문:
한국어·영어에서 보존할 사실과 뉘앙스:
```

- 첫 문단은 실제 장면, 행동, 의문 중 하나로 시작한다. 주제를 소개하는 교과서식 정의로 시작할 이유가 있으면 그 이유가 본문에 드러나야 한다.
- 자신의 관찰과 일반적 사실을 구분한다. 경험이 없는 분야의 일화를 1인칭으로 만들지 않는다.
- 구체적 사례가 중심이다. 기술 설명은 그 사례를 이해하는 데 필요한 만큼만 둔다.
- 제목과 요약은 본문에서 실제로 다룬 내용을 약속한다. 클릭을 위한 과장이나 본문에 없는 결론을 넣지 않는다.
- 끝 문단은 앞에서 한 말을 다시 요약하지 않는다. 생각이 멈춘 지점, 남은 질문, 돌아오는 장면이 더 적합하면 거기서 끝낸다.
- 편집 후 첫 문단과 마지막 문단을 소리 내어 읽는다. 어느 개인 블로그에나 붙일 수 있는 문장이면 다시 쓴다.

## 검토 결과 기록

변경 설명이나 작업 기록에 다음을 남긴다. 게시 승인 자체를 코드나 자동 점수로 가장하지 않는다.

```text
바꾼 페이지/언어:
말투 기준과 구체적 근거:
새로 넣은 사실의 출처:
샘플/초안/공개 상태:
빌드·링크·화면 확인 결과:
사용자 본인 말투 확인: 완료 / 미확인
```

2026-09-28 사용자는 `jjgo-blog-writing` 스킬 실행에 대표 이미지 생성과 사이트 배포까지 포함하도록 승인했다. 이 경로에서는 편집과 사실 확인을 마친 글을 `sample: false`로 반영하고 별도의 말투 승인 질문 없이 검증·배포한다. 초안만 요청한 경우에는 공개 경로 밖에 저장하거나, 사이트에 샘플로 올려달라는 요청이면 `sample: true`를 사용한다. 실제로 확인하지 않은 과거 경험이나 발언을 만들어 넣지 않고, 가상의 사례는 가정임이 드러나게 쓴다. 개인의 말투를 보장한다는 자동 검사나 AI 탐지 점수는 사용하지 않는다.
