ggoboong

GitHub 이슈에 쌓인 생각을 읽고 정리와 댓글 흐름을 도와주는 개인 봇

아카이브 · 2026년 5월 11일 오픈
  • GitHub Issue
  • 개인 봇
  • 아이디어 정리
  • 댓글 보조

왜 만들었나요?

개인 프로젝트를 하다 보면 아이디어와 할 일이 GitHub 이슈에 계속 쌓인다. 하지만 이슈가 많아질수록 어떤 생각을 이어가야 하는지, 어디까지 정리했는지 다시 보는 데 시간이 든다.

ggoboong은 GitHub 이슈를 단순한 작업 목록이 아니라 아이디어 대화 공간처럼 쓰기 위해 만들었다. 이슈와 댓글 흐름을 읽고, 필요한 정리와 다음 대화를 이어가기 쉽게 돕는 작은 개인 봇이다.

어떻게 사용하나요?

  1. GitHub 이슈에 아이디어나 작업 내용을 남긴다.
  2. 필요한 이슈에 정해둔 라벨을 붙인다.
  3. CLI 또는 봇을 실행해 대상 이슈를 읽는다.
  4. 이슈 내용과 댓글 흐름을 확인한다.
  5. 필요한 정리나 응답 댓글을 남겨 다음 작업을 이어간다.

주요 기능

  • 라벨 기반 이슈 읽기

    정해둔 라벨이 붙은 GitHub 이슈를 찾아 읽는다.

  • 댓글 흐름 확인

    이슈에 남긴 대화와 댓글 흐름을 함께 확인한다.

  • 응답 보조

    필요한 정리나 다음 댓글 작성을 도와준다.

  • 중복 처리 방지

    이미 처리한 댓글을 다시 처리하지 않도록 표시를 남긴다.

  • GitHub App 기반 동작

    GitHub App 권한 안에서 안전하게 동작하도록 구성할 수 있다.

이런 사람에게 좋습니다

  • GitHub 이슈를 개인 아이디어 노트처럼 쓰는 사람
  • 프로젝트 아이디어와 작업 메모가 이슈에 많이 쌓이는 사람
  • 반복적인 이슈 확인과 댓글 작성을 줄이고 싶은 사람
  • 자동화는 원하지만 최종 판단은 사람이 직접 하고 싶은 개발자

현재 상태

개인 GitHub 작업 흐름을 실험하기 위해 만들었고, 현재는 아카이브한 서비스입니다.

GitHub 이슈를 대화형 작업 공간처럼 사용할 수 있는지 확인한 실험 기록으로 남겨두었습니다.

배운 점

  • GitHub 이슈는 작업 티켓뿐 아니라 아이디어를 쌓는 공간으로도 쓸 수 있다.
  • 자동화 봇은 할 일을 대신 결정하기보다, 사람이 다시 생각을 이어가기 쉽게 도와줄 때 더 자연스럽다.
  • 라벨 기반 흐름은 단순하지만 개인 자동화에는 충분히 효과적이다.
  • 댓글 중복 처리 방지 같은 작은 장치가 봇 운영 안정성에 중요하다.
