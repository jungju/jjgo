쇼츠생성기

짧은 영상 아이디어를 화면 단위로 구성하고 자동화 흐름을 실험한 서비스

아카이브 · 2024년 9월 1일 오픈
  • 쇼츠 제작
  • 영상 자동화
  • 화면 구성
  • 실험 서비스

왜 만들었나요?

짧은 영상은 길이는 짧지만, 만들 때는 생각보다 반복 작업이 많다. 문구를 넣고, 장면을 배치하고, 미리보기를 확인하고, 다시 수정하는 과정이 계속 반복된다.

쇼츠생성기는 이런 반복 편집을 줄이고, 정해진 형식의 짧은 영상을 더 빠르게 만들 수 있는지 실험하기 위해 만들었다.

어떻게 사용하나요?

  1. 만들고 싶은 짧은 영상 아이디어를 정리한다.
  2. 화면에 들어갈 문구와 장면 요소를 배치한다.
  3. 전체 흐름을 미리보기로 확인한다.
  4. 어색한 문구나 장면을 빠르게 수정한다.
  5. 반복되는 쇼츠 제작 흐름을 자동화할 수 있는지 확인한다.

주요 기능

  • 화면 단위 구성

    짧은 영상을 여러 화면 단위로 나누어 구성한다.

  • 텍스트 배치

    영상에 들어갈 제목, 문구, 설명 요소를 배치한다.

  • 장면 흐름 편집

    화면 전환과 콘텐츠 흐름을 조정한다.

  • 미리보기 확인

    완성 전에 결과 흐름을 빠르게 확인한다.

  • 반복 수정 중심

    문구와 장면을 여러 번 고치기 쉬운 저작 화면을 제공한다.

이런 사람에게 좋습니다

  • 짧은 영상 제작 과정을 자동화해보고 싶은 사람
  • 비슷한 형식의 쇼츠를 반복해서 만들어야 하는 사람
  • 영상 편집보다 콘텐츠 구조와 문구 작성에 집중하고 싶은 사람
  • AI나 템플릿 기반 영상 제작 흐름을 실험하고 싶은 개발자

현재 상태

짧은 영상 제작 자동화를 실험하기 위해 만들었고, 현재는 아카이브한 서비스입니다.

화면 구성, 텍스트 배치, 미리보기 중심의 쇼츠 제작 흐름을 확인한 실험 기록으로 남겨두었습니다.

배운 점

  • 쇼츠 제작은 편집 기술보다 반복되는 구성 흐름을 줄이는 것이 중요하다.
  • 영상 자동화는 완전 자동 생성보다 수정하기 쉬운 저작 화면이 먼저 필요하다.
  • 화면 단위로 쪼개면 문구, 장면, 흐름을 관리하기 쉬워진다.
  • 미리보기와 빠른 수정 흐름이 있어야 실제 제작 도구로 쓸 수 있다.
