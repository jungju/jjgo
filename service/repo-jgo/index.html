반복되는 내 작업 흐름을 대신 실행해보는 AI 캐릭터 실험

아카이브 · 2026년 2월 13일 오픈
  • AI 캐릭터
  • 개인 자동화
  • 작업 대리자
  • 실험 서비스

왜 만들었나요?

매일 비슷하게 반복하는 작업은 많지만, 매번 직접 판단하고 실행하다 보면 생각보다 에너지가 많이 든다. 그렇다고 큰 자동화 플랫폼을 쓰기에는 설정이 무겁고, 내가 원하는 작은 흐름을 빠르게 실험하기 어렵다.

jgo는 내가 자주 하는 작업 흐름을 작은 AI 캐릭터에게 맡겨보면 어떨지 실험하기 위해 만들었다. 완벽한 자동화보다, 내 방식으로 일하는 작은 대리자를 만들어보는 데 초점을 두었다.

어떻게 사용하나요?

  1. 반복해서 실행하는 작업이나 명령을 정리한다.
  2. jgo가 처리할 수 있는 작은 흐름으로 묶는다.
  3. 필요한 순간에 같은 방식으로 실행한다.
  4. 실행 결과를 확인하고 다음 작업으로 이어간다.
  5. 반복되는 수동 작업을 줄이면서 개인 작업 루틴을 다듬는다.

주요 기능

  • 반복 작업 실행

    자주 사용하는 명령이나 작업을 정해둔 흐름으로 실행한다.

  • 작업 흐름 정리

    흩어진 개인 작업을 하나의 실행 단위로 묶어 관리한다.

  • 실행 결과 확인

    작업이 어떻게 실행됐는지 다시 확인하기 쉽게 남긴다.

  • 개인 루틴 자동화

    내 작업 방식에 맞는 작은 자동화 루틴을 구성한다.

  • AI 캐릭터 실험

    단순 도구가 아니라 나를 돕는 작은 대리자처럼 동작하는 흐름을 실험한다.

이런 사람에게 좋습니다

  • 반복 작업을 줄이고 싶은 개인 개발자
  • 복잡한 자동화 플랫폼보다 가벼운 개인 도구를 선호하는 사람
  • 자신의 작업 방식을 작은 자동화 흐름으로 만들고 싶은 사람
  • AI를 단순 챗봇이 아니라 작업 대리자로 실험해보고 싶은 사람

현재 상태

개인 작업 자동화와 AI 캐릭터 흐름을 실험하기 위해 만들었고, 현재는 아카이브한 서비스입니다.

반복 작업을 작은 대리자에게 맡기는 방식이 실제로 자연스러운지 확인한 실험 기록으로 남겨두었습니다.

배운 점

  • 개인 자동화는 거창한 플랫폼보다 작은 반복 작업 하나에서 시작하는 것이 좋다.
  • AI 캐릭터는 말투보다 “어떤 일을 대신 해주는가”가 더 중요하다.
  • 자동화 흐름은 사용자가 직접 이해할 수 있을 만큼 단순해야 오래 쓸 수 있다.
  • 실행 결과와 실패 이유를 다시 확인할 수 있어야 신뢰가 생긴다.
